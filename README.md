# ksm — Android Keyboard

Clean, standalone Android keyboard project prepared for a separate GitHub repository.

## Build with GitHub Actions
1. Create a new repository named `ksm`.
2. Upload the contents of this folder to the repository root.
3. Open **Actions** and run **Android Build** (or push a commit).
4. Download the `ksm-debug` artifact from the completed workflow.

Package: `com.ksm.keyboard`  
Minimum Android version: Android 6.0 (API 23).
